Chapter 1

Introduction to Data Science

What & why

Data Science is an interdisciplinary field that extracts valuable insights and knowledge from data by combining statistics, computer science, mathematics, and domain expertise.

Why it exists: traditional analysis methods fail on modern data because of its massive volume, speed, and unstructured/diverse nature — more than a human can process manually.

The Data Science Venn Diagram (Drew Conway)

Substantive expertiseDomain/business knowledge used to frame questions and interpret results

Introduction to Python

A versatile language favoured for its clean syntax and rich library ecosystem (via standard tools or the Anaconda distribution).

  • Basics: # starts a comment; variable names are case-sensitive (Age and age are different variables) with automatic type inference.
  • Control flow: conditionals (if, elif, else) and loops (for, while).
  • Data structures: Lists (ordered, mutable), Tuples (ordered, immutable), Dictionaries (key–value pairs), Sets (unordered, unique elements).
  • Functions: reusable blocks of code defined with def.
# comments, case-sensitive names, data structures
Age = 21
age = 34  # a different variable to Age

fruits_list  = ["apple", "pear"]      # ordered, mutable
coords_tuple = (10, 20)               # ordered, immutable
student_dict = {"name": "Zanele", "age": 21}
unique_set   = {1, 2, 2, 3}            # {1, 2, 3}

def greet(name):
    if name:
        return f"Hello, {name}!"
    else:
        return "Hello!"

Quantitative vs. qualitative data

Quantitative — numerical quantities where mathematical operations are possible, collected via surveys or experiments. Qualitative — descriptive information categorised by language or characteristics rather than numbers, collected via interviews or observations.

Four levels of data measurement
LevelMeaningExample
NominalNamed categories, no natural orderGender, nationality
OrdinalRank order, but differences aren't measurableProduct ratings, satisfaction scales
IntervalDifferences are meaningful, no true zeroTemperature (°C/°F)
RatioOrder + meaningful difference + multiply/divide, has an absolute zeroHeight, weight, sales revenue
Descriptive statistics with NumPy

NumPy is the fundamental package for scientific computing in Python, built around the N-dimensional array (ndarray), supporting efficient vectorisation, broadcasting, and matrix operations.

  • Central tendency: mean, median, mode — identifying typical values.
  • Spread: range, variance, standard deviation — standard deviation is the average distance data points lie from the mean.
Introduction to Pandas

An open-source data manipulation and cleaning library built on top of NumPy. Core structures: the Series (a 1D labelled array/column) and the DataFrame (a 2D labelled, spreadsheet-like structure).

Five Steps of Data Science

StepWhat it involves
1. Ask an interesting questionCuriosity-driven formulation of problems that dictate the value of the final insights
2. Obtain the dataGathering data from public databases, surveys, sensors, or web sources
3. Explore the dataExamining structure, identifying row/column types, handling missing values, managing duplicates and outliers using Pandas
4. Model the dataApplying statistical or machine learning techniques to test hypotheses and uncover predictive patterns
5. Communicate & visualise resultsTranslating technical findings into clear narratives and charts for stakeholders
Pandas data operations
  • Inspection: df.head(), df.describe(), df.shape, df.isnull().sum()
  • Manipulation & cleaning: df.dropna(), df.fillna(), df.drop_duplicates(), adding columns, conditional/boolean filtering
  • Aggregation: df.groupby().mean() to summarise subsets of data
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()                       # peek at the data
df.isnull().sum()               # count missing values per column
df = df.dropna()                # drop rows with missing data
df = df.drop_duplicates()
high_sales = df[df["Revenue"] > 1000]   # boolean filter
df.groupby("Region")["Revenue"].mean()  # aggregate

Data Visualisation using Matplotlib

Matplotlib is an open-source plotting library providing both a procedural interface (pyplot) and an object-oriented interface.

Visual hierarchy
TermMeaning
FigureThe top-level container — the window/page holding all plot elements
AxesThe actual plot area — data space, ticks and labels
SubplotsA grid of multiple Axes within a single Figure
Core plot types
TypeFunctionBest for
Line plotplt.plot()Trends over time / sequential data
Bar chartplt.bar()Comparing discrete categories or frequency distributions
Scatter plotplt.scatter()Relationships/correlations between two continuous variables
Customisation

Colours, markers, line styles, titles, axis labels (set_xlabel, set_ylabel), legends, grids, and layout adjustments (plt.tight_layout()) to prevent overlapping elements.
